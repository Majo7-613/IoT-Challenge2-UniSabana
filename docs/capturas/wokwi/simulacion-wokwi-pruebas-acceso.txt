SIMULACIÓN — Pruebas de acceso al tablero servido por el ESP32 simulado en Wokwi
Fecha: 05/10/2026. Extensión de Wokwi para VS Code, reenvío localhost:8180 -> puerto 80. Firmware: commit 52aa808 (entorno wokwi).
Herramientas: curl (Digest) y un cliente WebSocket en Python. Las credenciales y el token se leyeron de secrets.h y no se registran aquí.
En el entorno wokwi el filtro de subred está desactivado (ajuste de simulación); no se prueba aquí.
